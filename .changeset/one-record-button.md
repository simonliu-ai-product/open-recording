The record button now carries the source, and the navigation stops pretending three filters are three pages.

Choosing what to record lived in the bottom-left corner while recording lived in the middle of the page, so recording a tab meant crossing the window between two halves of one action — and the corner's "Arm microphone" was the only brand-coloured button in the sidebar, reading as the app's main action while competing with the real one.

Pressing record now takes a source if none is held and starts, all in one place. A caret beside it picks between the microphone and a browser tab, remembers the choice, and takes it there and then, because a permission prompt and Chrome's tab picker both need the click. A line under the button says what is in hand and how many studio tabs are open.

`Recordings`, `Transcribed`, and `Pending` rendered the same cards over the same recordings. They are one entry now, with the filter beside the search and sort where it belongs.
